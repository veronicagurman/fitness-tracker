# Fitness Tracker

iOS-приложение для отслеживания здоровья на SwiftUI. Сейчас реализован учёт воды со статистикой и целью, остальные разделы в разработке.

## Возможности

- Добавление выпитой воды (выбор объёма в мл)
- Подсчёт выпитого за сегодня
- Графики статистики по периодам: день, неделя, месяц, год (по месяцам)
- Дневная цель по воде с настройкой и линией цели на графиках
- Хранение данных на устройстве (SwiftData), цель сохраняется между запусками (UserDefaults)

## Стек

Swift, SwiftUI, SwiftData, Swift Charts, архитектура MVVM (`@Observable`), UserDefaults (`@AppStorage`)

## Запуск

1. Открыть `FitnessTracker.xcodeproj` в Xcode
2. Выбрать симулятор iPhone
3. Нажать Run (Cmd + R)

## Планы

- Разделы: шаги, сон, тренировки
- Главный экран с приветствием и погодой
